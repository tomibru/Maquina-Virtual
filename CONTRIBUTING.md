Guía para contribuir

Reglas básicas del grupo:
- Workflow: crear ramas con el prefijo feature/ o fix/ (ejemplo: feature/instrucciones-basicas)
- Abrir Pull Request para revisar cambios antes de mergear a main
- Usar mensajes de commit claros: "feat: agregar decodificador de instrucciones"
- Código en C debe compilar con: make
- Ejecutar pruebas (si se agregan) antes de abrir PR

Responsabilidades:
- Coordinar tareas en Issues
- Asignar reviewers para cada PR

Comunicación:
- Usar la descripción del PR para explicar cambios y cómo probarlos
